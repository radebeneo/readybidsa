## Accessibility

- Target: WCAG 2.2 level AA unless the client requires more.
- All interactive elements work with a keyboard and have a visible focus state.
- Images have meaningful alternative text, or empty alternative text if decorative.
- Colour is never the only way information is shown.
- Every brand theme meets the colour contrast target. Check contrast whenever a theme changes.

## Rules for agents

- Use design tokens for every colour, font, size, spacing, radius, shadow and breakpoint. Never hard-code a raw value, such as a hex code or pixel size, where a token exists.
- Use semantic or component tokens, not primitive tokens, so components work in every brand theme.
- Reuse an existing component before creating a new one. A new component must be listed in the unit spec.
- Never recreate, redraw or alter a logo. Use the asset files named in the brand file.
- Write copy in the voice described in the brand file. Never invent claims, statistics, prices or legal text.
- Check every change in each brand theme it affects.
- If the designs and the context files disagree, stop and ask which is right.
